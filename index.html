my-album

Offline photo browser · Dependency-free · Local-first

  1. Place this project next to a folder containing your photos. Each immediate subfolder becomes an album.
  2. Select the photo folder below.
  3. You can also drag the folder onto this page.

For security, browsers require an explicit folder selection before a local page can read files. Your browser may remember the permission for future visits. Chrome and Edge provide the most complete experience.
